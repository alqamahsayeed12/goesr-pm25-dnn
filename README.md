# GOES-R PM2.5 Estimation Pipeline

A reproducible, modular pipeline to estimate surface-level PM2.5 concentrations from GOES-R satellite AOD and HRRR meteorological data using deep learning models.

## Highlights
- High-resolution PM2.5 inference at continental U.S. scale
- Ensemble of regionally tuned DNN models
- Fully open-source, ready for large-scale deployment
- Real-time and historical processing supported
